# Aktiedagbok

En mobilvänlig logg över aktieköp och sälj. Fyll i två av belopp, antal och kurs så räknas det tredje ut. Appen håller koll på antal ägda aktier, balans sedan start, GAV, realiserad och orealiserad vinst samt resultat per aktie.

- All data sparas lokalt i webbläsaren på telefonen. Inget skickas någonstans.
- Exportera en CSV-säkerhetskopia (kan sparas i Google Drive och öppnas i Google Kalkylark) och importera den igen vid behov.
- Fungerar offline och kan läggas på hemskärmen som en app.

Sidan är en enda fil, `index.html`, och körs via GitHub Pages.
